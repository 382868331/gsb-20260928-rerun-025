# 机器人定位系统（离线核心 · A 轮）

纯 Python 离线运行的机器人定位核心。本轮融合**虚构轮速**与**虚构惯性**观测，
输出随时间变化的位置、朝向与误差范围（协方差）；地图匹配仅预留接口，后续再加。
所有数据均为仿真生成，**不读取任何真实设备**。

## 设计原则

传感器接入、状态估计、记录回放三层解耦，各自可独立替换：

| 层 | 文件 | 职责 |
| --- | --- | --- |
| 数据结构 | `robotloc/types.py` | 轮速/IMU 消息、位姿估计输出 |
| 传感器接入 | `robotloc/sources.py` | `SensorSource` 协议；内存源、JSONL 回放源 |
| 状态估计 | `robotloc/estimator.py` | 5 维误差状态 EKF（x, y, θ, v, ω） |
| 因果管线 | `robotloc/pipeline.py` | 迟到消息、断流推演、检查点 |
| 记录回放 | `robotloc/recording.py` | 消息与输出统一落 JSONL |
| 地图匹配 | `robotloc/mapping.py` | 仅接口占位（本轮不实现） |
| 样例/评估 | `robotloc/scenario.py`, `robotloc/evaluate.py` | 已知真值路径、误差指标 |

接真实设备时只需实现 `SensorSource`；换估计算法时保持
`update_wheel/update_imu/checkpoint/restore` 接口即可，管线无需改动。

## 因果性与鲁棒性

- **不用未来观测**：处理按消息到达时刻 `received_at` 推进，只送入测量时刻
  `t <= now` 的观测；消息同时记录测量时刻与到达时刻。
- **迟到消息**：测量时刻早于已提交水位时，回滚到之前最近的检查点，把迟到
  消息与区间原消息按时间序重放。测试保证“迟到”与“准时到达”结果逐位一致。
- **短暂缺失/断流**：超过 `gap_timeout` 无任何消息时，按固定步长纯推演并把
  输出标记为 `fresh=false`；EKF 过程噪声使位置/航向协方差持续增长，不会在
  断流后继续声称精度不变。
- **轮速打滑**：基于新息平方（NIS）的卡方门限，异常轮速先自适应放大观测
  噪声（降权），极端突变直接拒绝该帧。恒速、两轮同比例打滑在无外部参照时
  物理上不可完全观测，这是后续地图匹配要解决的可观性问题。
- **检查点**：检查点即估计器完整状态（JSON，无 pickle）。保存后恢复继续跑，
  测试保证与一次性完整回放的位姿输出差 < 1e-10。

## 输出

每个输出点含：时间、`(x, y, θ)`、5×5 协方差、`fresh` 标志。
演示还导出位置 1σ、航向 1σ 随时间变化的 CSV。

## 运行

```bash
python -m scripts.run_demo --out runs/demo
```

产物：

- `runs/demo/messages.jsonl`：原始消息（含测量/到达时刻，可原样重放）
- `runs/demo/poses_full.jsonl`：完整回放的位姿与协方差
- `runs/demo/trajectory.csv`：时间序列轨迹与误差范围
- `runs/demo/summary.json`：误差指标、迟到/断流统计、回放与检查点一致性

典型结果（种子固定）：位置 RMS ≈ 0.24 m，最大 ≈ 0.36 m，航向 RMS ≈ 0.45°；
文件回放与检查点恢复相对完整回放最大差 = 0。

## 测试

```bash
python -m pytest -q
```

覆盖：直行积分、协方差随断流增长、时间倒流拒绝、检查点逐位等价、
打滑降权、端到端已知路径误差、迟到回滚等价、断流输出标记、
保存/恢复等价、文件回放等价。

## 依赖

Python 3.10+、numpy、pytest（仅测试）。
